# 光影筆記 · 91 招拍攝技巧

這是一個為手機與電腦使用設計的攝影技巧網頁，整理 **101 招拍攝技巧、19 個原始來源與 8 個主題系列**，包含男生／女生、人像、風景、建築、夜景、動態、曝光、快門與調色等內容。

## 1. 怎麼打開

### 方法 A：直接開啟（最簡單）
1. 解壓縮整個資料夾。
2. 直接雙擊 `START.bat`。
3. 系統會自動開啟本機網站。

### 方法 B：直接打開 `index.html`
若只是快速瀏覽，也可以直接雙擊 `index.html`。  
但若要使用 **離線準備、PWA 安裝、更新檢查**，建議仍用 `START.bat`。

---

## 2. 出門前先做「離線準備」
右上角有 **`⇩ 離線準備`**。

建議第一次使用時先下載：
- **網頁核心**：必要。
- **預覽圖片**：101 張圖卡縮圖。
- **完整圖片**：101 張 Reader 完整圖。

全部下載後，即使沒有網路，也能繼續查看本站內容。

> 外部來源（Facebook / IG / Threads）仍需要連網才能打開原始貼文。

## 4. Reader（完整閱讀）
點任一圖卡可開啟 Reader：
- 查看完整圖片
- 看一句話技巧
- 左右切換同來源 / 同主題內容
- 手機可左右滑動
- 點外側留白或 `×` 可離開

---

## 5. 圖片放大

圖卡中的圖片可以直接點擊放大；Reader 裡的完整圖片也可以再次點擊放大。

- **手機**：適合畫面時左右滑可切換同來源／同主題的上一張、下一張；雙指縮放後則改為拖曳查看細節。
- **電腦**：滑鼠滾輪縮放、按住拖曳。
- 雙擊圖片可在放大與適合畫面間切換。
- 視窗四周保留留白，點外側、`×` 或「完成」即可離開。
- 點圖片會放大；點卡片文字區則仍是進入 Reader。
- **Lightbox 不會因換圖而關閉**：切換後仍停留在同一個放大介面，每張新圖會回到「適合畫面」。
- 若從 Reader 開啟 Lightbox，切換圖片時底下的 Reader 也會同步到相同 TIP，關閉放大後可直接接著看。

## 6. 收藏與隨機
- `♡`：只看收藏
- `↻`：隨機一招

如果目前有套用篩選，隨機會從目前結果中抽；沒有篩選時，會從全部 **101 招** 中抽一張。

## 8. 更新與版本
更新機制比照雲南版：
- 網站核心依 **Version + Build** 檢查更新。
- 圖片依 **SHA-256** 判斷是否需要重新下載。
- 一般更新不會清除收藏、離線設定與介面偏好。
