# 光影筆記 · 87 招拍攝技巧

這是一個為手機與電腦使用設計的攝影技巧網頁，整理 87 招拍攝技巧、17 個原始來源與 8 個主題系列，包含男生／女生、人像、風景、建築、夜景、動態、曝光、快門與調色等內容。

## 開啟網站

電腦本機版請先解壓 ZIP，再雙擊 `START.bat`。啟動後會自動開啟瀏覽器，使用期間請保持命令視窗開啟。

`START.bat` 使用 Windows 內建 PowerShell 啟動 localhost，不需要 Python、Anaconda 或額外安裝套件；若預設連接埠被占用，會自動改用其他可用連接埠。

不建議直接雙擊 `index.html` 作為正式使用方式，因為 `file://` 無法完整使用 Service Worker、PWA 與離線準備功能。

### 出門拍照前先做一次離線準備

1. 在有網路時用 `START.bat` 開啟網站。
2. 點右上角 **「⇩ 離線準備」**。
3. 選擇要準備的內容：
   - **網頁核心**：必要，包含介面、資料、分類與收藏功能。
   - **預覽圖片**：87 張圖卡縮圖，約 4.2 MB。
   - **完整圖片**：87 張 Reader 完整圖，約 6.7 MB。
4. 按 **「下載已選內容」**，等待畫面顯示已完成。
5. 建議關閉網路後重新開啟一次，確認技巧與圖片可正常瀏覽。

離線準備會實際檢查 Cache，不只是記錄完成狀態。若有缺檔，可直接重試缺少項目，也可重新檢查或清除離線圖片。

Facebook / Instagram / Threads 等原始來源頁仍需要網路才能開啟。

## 兩種瀏覽方式

頁面上方可切換 **依來源 / 依主題**。

### 依來源

同一支 Facebook Reel / Share 的技巧放在一起，適合回頭確認某一支原始影片整理出了哪些技巧。

- 手機：同一來源以疊卡顯示，可左右滑動。
- 電腦：同一來源集中在一個系列區塊。
- Reader：左右滑動只切換同一來源內的技巧。

目前共有 17 個來源系列。

### 依主題

把不同來源中相近的拍攝技巧重新整理在一起，適合現場直接找「現在要怎麼拍」。

目前 8 個主題：

- **人像構圖與機位**
- **曝光與基礎**
- **快門與動態**
- **人像姿勢**
- **戶外旅拍**
- **人像調色**
- **建築人像**
- **夜景人像**

Reader 會跟著目前瀏覽方式切換；在「依主題」模式點開圖卡後，左右滑動會瀏覽同一主題的其他技巧，而不是跳回原始來源分組。

## 搜尋與分類

除了來源／主題模式外，還可以使用多層篩選縮小範圍：

- **人物／內容**：男生、女生、人像、風景、建築、夜景、動態、調色、攝影基礎。
- **拍法**：站姿、坐姿、全身、半身、低機位、高機位、廣角、長焦、抓拍、構圖、曝光、快門、閃光燈、逆光、人像模式、後製。
- **圖片類型**：人像圖、風景圖、建築圖、夜景圖、動態圖、教學圖。
- **搜尋**：可直接輸入「0.5×、低機位、夜景、坐姿」等關鍵字。

男生／女生標籤是依 **示意圖片中實際出現的主要人物** 判斷，不代表該技巧只能給特定性別使用。沒有明確人物的風景、曝光或教學圖不會硬套性別標籤。

## 圖卡與 Reader

### 手機

首頁以系列疊卡呈現，同一系列可直接左右滑動預覽；點圖卡後會開啟完整 Reader。

Reader 中可以：

- 左右滑動上一招／下一招。
- 查看完整圖片與一句話技巧。
- 查看圖片類型、場景、拍法、系列與人物標籤。
- 收藏目前技巧。
- 開啟原始來源頁。

網站會記住每個系列最後看到的位置，下次回到該系列時會接續原本的卡片。

### 電腦

同一來源或主題會集中在一個系列區塊，避免 87 張圖片全部混在同一個大 Grid。可直接從系列區塊點開任一圖卡進入 Reader。

## 收藏與隨機一招

右上角 `♡` 可只看目前瀏覽器收藏的技巧；每張圖卡與 Reader 內都可加入／取消收藏。

收藏只保存在目前瀏覽器，不會自動同步到其他電腦或手機。

`↻` 為 **隨機一招**，會從目前篩選結果中隨機開啟一個技巧；若沒有套用篩選，則從全部 87 招中隨機選擇。

## 介面版面

右上角 `⚙` 可選擇介面版面：

| 名稱 | 定義 |
| --- | --- |
| **手機版（預設）** | 手機的一般 responsive 介面，使用系列疊卡與觸控操作。 |
| **電腦版** | 在手機上載入完整桌面寬度並縮放，適合想一次看到更多內容時使用。 |

版面選擇會保存在目前瀏覽器，下次開啟仍會沿用。

## 彈跳視窗

Reader、離線準備與介面設定的彈窗版型直接沿用雲南版的 inset dialog 規則。

手機版主要彈窗固定約為 **90% 螢幕寬、80% 螢幕高**，四周會保留明顯的暗色背景縫隙，不會再貼滿整個螢幕。可以：

- 點視窗外側暗色區域離開。
- 按 `×` 或返回。
- Reader 內左右滑動切換同系列技巧。
- 電腦可按 `Esc` 關閉。

Reader 內的圖片、標題、資訊格、上下列與導覽排列也改用雲南版 Detail Reader 的節奏；圖片以完整顯示為主，不會為了填滿視窗強制裁掉內容。

## 檢查更新

右上角 `⚙` → **介面版面** 的下方會顯示目前軟體版本，並提供：

- **檢查更新**：檢查 `build.json`，確認網站核心與目前已快取圖片是否為最新版。
- **強制重新載入**：重新抓取 HTML / CSS / JS / 資料檔，再核對圖片 Cache，最後重新載入頁面。

更新機制與雲南版相同：網站核心依 Build 管理，圖片使用穩定 Cache；圖片以 SHA-256 比對，內容沒有改變就不會重新下載全部 174 張圖片。收藏、版面與其他瀏覽器偏好不會因一般更新被清除。

## 顯示主題

右上角 `◐` 可以切換淺色／深色介面。主題偏好會保存在目前瀏覽器。

## 圖片與來源

網站共整理 87 張完整圖片與 87 張預覽縮圖。相同原始 Facebook / Instagram / Threads 來源的圖片會一起管理，因此「依來源」模式能直接看到同一支影片整理出的完整技巧組。

網頁中的 **人像圖 / 風景圖 / 建築圖 / 夜景圖 / 動態圖 / 教學圖** 是瀏覽分類，不代表硬碟上也用同樣方式存放。

每個技巧 Reader 都保留來源連結；來源頁、影片是否仍存在，以及平台能否正常開啟，仍取決於 Facebook / Instagram / Threads 等平台本身。

## 離線與 PWA

離線準備完成後，網頁核心、已下載縮圖與完整圖片可以在沒有外網時使用。網站會分開保存核心檔與圖片，因此程式更新時不需要無條件重新下載所有圖片。

Android Chrome 若瀏覽器支援 PWA，可加入主畫面使用；瀏覽器仍可能因裝置儲存空間管理而清除網站 Cache，出發前建議重新執行一次「離線準備 → 重新檢查」。

## 使用提醒

拍攝技巧是構圖、機位、曝光與姿勢的參考，不代表每個場景都必須完全照做。現場光線、鏡頭焦段、人物比例與背景距離都會影響結果，可先照著示例拍一張，再依畫面微調。

來源影片與社群貼文可能被刪除、改權限或限制登入；網站內已整理的文字與本地圖片不會因此自動消失，但「查看來源」可能需要連網或登入平台。
