## 曝光控制

來源：[曝光誤區與向右曝光](https://www.facebook.com/reel/1063888769453150/)

### 14. 低 ISO 不一定最好

低 ISO 若嚴重欠曝，後製拉亮反而可能產生更多雜訊。

![低 ISO 欠曝雜訊](images/14_低ISO欠曝雜訊.jpg)

### 15. 低光提高 ISO

先守住安全快門與所需光圈，再提高 ISO 補足亮度。

![低光提高 ISO](images/15_低光提高ISO.jpg)

### 16. 保護高光

高光爆成純白就救不回來，優先保住重要亮部。

![高光溢出](images/16_高光溢出.jpg)

### 17. 包圍曝光

大光比靜態場景可拍包圍曝光，再合成 HDR。

![包圍曝光](images/17_包圍曝光.jpg)

### 18. 看直方圖

不要只看螢幕亮度，要用直方圖判斷曝光。

![直方圖判讀](images/18_直方圖.jpg)

### 19. 向右曝光

在高光不溢出的前提下，讓直方圖盡量靠右。

![向右曝光](images/19_向右曝光.jpg)

### 20. 後製壓回亮度

向右曝光的 RAW 可在後製壓暗，保留更多暗部資訊。

![後製壓回曝光](images/20_後製壓回曝光.jpg)
